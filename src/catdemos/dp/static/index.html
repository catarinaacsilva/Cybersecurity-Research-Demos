DP vs Profiling

Silva et al., Evaluating the Effectiveness of Differential Privacy Against Profiling (2025) · all demos

Differential privacy stops re-identification, but does it stop profiling? A census release of 9,000 real people is attacked in two ways while you add noise.

Hide all, then release only relationship exactly: nobody can be re-identified, yet "married" is still guessed almost perfectly. Hiding the classic identifiers (age, sex, race, country) protects neither.

How it works Local DP on each hidden field: Laplace noise for numbers, randomised response for categories, ε per field. Profiling: logistic regression trained on 6,000 released records, tested on 3,000 others; "power kept" is the share of its advantage over guessing that survives DP. Re-identification: an adversary who knows the true values of 800 people links each to the nearest released record. Data: UCI Adult census (CC BY 4.0).
